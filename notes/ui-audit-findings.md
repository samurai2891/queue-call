# UI/UX Audit Findings - All Pages

## 1. Home (/)
- ヘッダーにQueue Callロゴ、ダッシュボード、店舗設定、ユーザー名
- ヒーローセクション「順番待ちをスマートに」
- 「店舗にアクセス」カード（店舗IDを手入力）
- 「あなたの店舗」セクション（テスト、デモ店舗のカード）
- 「主な機能」セクション（6つの機能カード）
- 問題: 店舗カードのボタンが小さく密集、「店舗トップ」「スタッフ」「キオスク」「ボード」が横並びで分かりにくい
- 問題: ヒーローセクションのデザインが平坦で印象に残らない

## 2. StoreTop (/s/:slug)
- 店名「テスト」とWelcomeが中央配置
- Now CallingとGroups Waitingの小さなカード
- Join QueueとView Menuの2ボタン
- 言語切替は右上に小さく配置
- 問題: 余白が多すぎて情報密度が低い
- 問題: 「Now Calling」の値が「-」で意味不明
- 問題: 背景が薄いグレーで殺風景、ブランド感なし
- 問題: 店名のフォントサイズが大きいが装飾なし
- 問題: 待ち状況の視覚的インジケーターがない

## 3. JoinQueue (/s/:slug/join)
- 「Join Queue」タイトル
- Party Size（-/+ボタンで2名選択）
- Notes (optional) テキストエリア
- Get Ticketボタン（青）
- 左上に戻るボタン、右上に言語切替
- 問題: カードが画面中央に小さく配置、タッチターゲットが小さい
- 問題: -/+ボタンが小さく高齢者には押しにくい
- 問題: 人数選択のUIがシンプルすぎて直感的でない
- 問題: 現在の待ち状況が表示されない（何組待ちか分からない）

## 4. Menu (/s/:slug/menu)
- 上部にFeed/Listタブ切替
- 右上にフルスクリーンボタン、言語切替
- 「Use browser translation if you need a translated menu.」の注意書き
- 空の場合「No menu items」アイコン
- 問題: 空状態のデザインが貧弱
- 問題: 翻訳の注意書きが英語のまま

## 5. Board Display (/s/:slug/board/display)
- 店名「テスト」が上部中央
- 「No one waiting」が中央に表示
- 右上にサウンドミュートボタン
- 問題: 空状態のデザインが非常に貧弱、大画面表示を想定しているのに情報がほぼない
- 問題: 背景がグラデーションだが薄すぎて視認性に欠ける
- 問題: 時計や日付の表示がない
- 問題: 店舗のブランディング要素がない

## 6. Kiosk Display (/s/:slug/kiosk/display)
- 言語選択画面（日本語/English）
- 選択後: 店名「テスト」、来店人数（-/+で2名）、発券するボタン、言語を変更リンク
- 問題: 言語選択画面が中央に小さく配置、タブレットでの操作を想定しているのにボタンが小さい
- 問題: 発券後のフローが分かりにくい
- 問題: 店舗のブランディング要素がない
- 問題: 人数選択の-/+ボタンが小さい

## 7. Staff (/s/:slug/staff)
- PINログイン画面
- 左上に戻るボタン、右上に言語切替
- 問題: ログインカードが画面中央に小さく配置
- 問題: PINの入力フィールドが小さい
- 問題: テンキーパッドがない（スマホのキーボードに依存）

## 8. Admin Settings (/admin/settings)
- 左上に戻るボタン、右上に保存ボタン
- 9つのタブ（基本設定、順番待ち設定、通知設定、メニュー設定、キオスク設定、ボード設定、予約、QRコード、セキュリティ）
- 問題: タブが多すぎて横スクロールが必要
- 問題: タブのアイコンが小さく、テキストも小さい
- 問題: 設定項目が1つのページに詰め込まれすぎ

## 9. Reservation (/s/:slug/reservation)
- 「予約受付停止中」カード
- 問題: カードが画面左上に配置され、中央寄せされていない
- 問題: デザインが貧弱で、店舗のブランディング要素がない

## 10. Checkin (/s/:slug/checkin)
- 「到着確認」カード
- 整理券番号入力フィールド
- 「到着を報告」ボタン
- 問題: カードが画面中央に小さく配置
- 問題: 番号入力のUIが小さい
- 問題: テンキーパッドがない

## 共通問題
- 全体的にタッチターゲットが小さい（飲食店のタブレット/スマホ操作に不適）
- ブランディング/店舗カラーの統一感がない
- 空状態のデザインが全ページで貧弱
- ナビゲーションの一貫性がない（ページによって戻るボタンの位置が異なる）
- モバイルファーストのデザインになっていない
- 視覚的階層が弱い（重要な情報と補助情報の区別がつかない）
- アニメーション/トランジションがほぼない
- フォントサイズが全体的に小さい
