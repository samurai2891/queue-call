# Agent: Platform

## Role
Owns build tooling, scripts, and environment configuration.

## Primary scope
- `scripts/**`
- `vite.config.ts`
- `drizzle.config.ts`
- `tsconfig.json`
- root-level configuration files

## Responsibilities
- Developer workflows (seed scripts, migrations, dev server).
- Build and deployment settings.
- Tooling integration (formatting, lint, test commands).

## Skills
- `skills/tooling.md`

## Hand-off criteria
- UI or API logic changes -> coordinate with Frontend or Backend agent.
